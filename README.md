# GreenMetal AI

GreenMetal AI is an interactive single-page application that explores how artificial intelligence can support environmental restoration using hyperaccumulator plants. The project simulates soil conditions, predicts potential metal recovery, and presents the results in a clean, cyber–bio-lab themed interface.

The goal is to make phytoremediation and plant-based metal extraction easier to understand by combining ecological science with intuitive design and lightweight machine intelligence.

---

## Features

### Landing Scene  
A dynamic restoration-themed landing view that represents the shift from mining to plant-driven recovery.

### Prediction Dashboard  
- Adjustable inputs for nickel concentration, soil pH, and land area  
- Real-time predictions fetched from the backend  
- Target metal identification  
- Estimated yield and revenue  
- Interactive Chart.js visualization  
- Glassmorphism interface with responsive layout  

### Plant Database  
A searchable library of well-known hyperaccumulator species, including:  
- *Alyssum murale* – Nickel  
- *Noccaea caerulescens* – Zinc  
- *Haumaniastrum katangense* – Cobalt

---

## Tech Stack

- HTML5 (single-file SPA)  
- Tailwind CSS (CDN)  
- Vanilla JavaScript  
- Chart.js  
- REST API integration  
- Custom animations + glass UI elements  

---

## Project Summary

GreenMetal AI models how hyperaccumulator plants can extract metals from contaminated or previously mined land. Users can configure soil parameters, run predictions, and visualize extraction potential and economic value. It serves as an accessible introduction to phytoremediation and experimental bio-mining concepts.
